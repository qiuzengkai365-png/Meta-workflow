本项目包含 44 个可直接复制执行的可执行 Prompt（步骤 16 / 模板 15 / 流程 13），配套 SOP 与 Workflow，全部以 HTML 单文件内嵌展示。

## 展示文件

- `Meta_Ads_提示词SOP_完整展示.html`：单文件展示页，内嵌全部 44 个 prompt 内容。点击卡片展开、支持搜索、按「步骤实现 / 模板 / 流程」分类筛选。直接用浏览器打开即可，无外部依赖。

## 内容说明

- 业务规则只采用已确认 SOP 内容；所有【待确认】事项原样保留，未确认前不补全、不创造数值阈值。
- 程序负责计算/清洗/存储，AI 负责判断/归因/文字生成，人工负责最终确认。
- 业务 SOP 整理完成 ≠ 程序开发完成。

## 使用方式

1. 打开 HTML 文件即可查看全部 prompt。
2. 顶部搜索框可按名称或内容检索；分类按钮切换步骤/模板/流程。
3. "全部展开"按钮可一次性展开所有 prompt 查看完整内容。
