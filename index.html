AI AUTOMATION PROJECT

Meta Ads Daily Analysis Skill

海外广告投放账户自动分析与日报生成系统

通过 Skill + Prompt + RAG + 自动化工作流，让 AI 代替人工完成广告账户的日常分析：从数据读取、异常定位、原因判断到优化建议与日报输出。

当前阶段：项目架构与文档体系已完成，程序开发与 API 接入尚未开始
01 / PROJECT GOAL

项目目标

不是单纯生成数据报表，而是让 AI 完成"分析—归因—建议—日报"的完整分析工作。

INPUT
账户数据输入
→
AI
自动分析账户
→
DETECT
识别异常
→
ADVISE
生成优化建议
→
OUTPUT
输出日报
业务范围：当前聚焦 Shopify 独立站在 Meta 平台的投放分析，覆盖 Account / Campaign / Ad Set / Ad 四层，CTR 前端流量与 CVR 后端转化双方向诊断。
02 / WORKFLOW

完整工作流

从数据获取到日报归档的端到端链路，共 12 个环节、3 道质量门禁。

数据获取→ 数据校验→ 指标计算→ 历史对比
账户结构分析→ 异常识别→ CTR / CVR 诊断→ 素材四象限
优化建议→ 日报生成→ 质量检查→ 交付归档
三道门禁：① 数据回传检查（超时则停止分析）；② 无条件下钻 Ad 层（每次分析必达素材层）；③ 日报质检（不通过退回修改，不放行交付）。
03 / SKILL ARCHITECTURE

完整 Skill 架构

四层分工：入口调度 / 分析执行 / 知识支撑 / 数据处理工具，各司其职不重复。

1

入口与调度层 — 主 Skill

统筹任务、编排模块顺序、决定放行或退回；不重复编写子模块规则。含主 Skill 定义、执行总流程、模块调用关系、输入输出规范。

2

分析执行层 — 20 个模块

12 个业务功能模块（数据获取到日报质检）+ 8 个系统支撑模块（调度、依赖、参数、存储、自动化、日志、测试、维护）。指标只在指标模块计算一次，完整诊断只在 Ad 层执行一次。

3

知识支撑层 — RAG 知识库

七大类别知识库，为分析提供指标定义、异常判断路径、平台知识、素材优化与转化漏斗参考。知识冲突时以已确认业务 SOP 为准。

4

数据处理工具层 — Data & Tools

承担字段映射、数据导入、指标计算、历史存储、API 接口、日报导出等确定性程序工作，与 AI 的业务判断分离。当前为目录占位，待开发。

PROMPT LIBRARY

16 份执行 Prompt

每个模块一份可复制、可执行的独立 Prompt，含角色、步骤、判断逻辑、输出格式等 12 项结构。

WORKFLOW SOP

13 份流程 SOP

覆盖完整日报工作流与各业务环节，含从需求到发布的 Skill 生成封装九阶段。

STATE TRACKING

六维状态追踪

按业务规则 / 文档 / Prompt / 程序 / 测试 / 总体六维度追踪每个模块的真实进度。

05 / SKILL BUILD SOP

Skill 生成 SOP

从需求调研到部署维护的完整封装流程，共九个阶段。

需求调研→ SOP 标准化→ 模块拆分→ Prompt 设计
RAG 建设→ Skill 封装→ 测试验收→ 部署维护
PHASE 1–2

需求与规则

收集 SOP、确认业务边界，标准化指标字典、异常判断与优化规则，标注待确认项。

PHASE 3–5

设计与知识

模块拆分与依赖定义、Prompt 工程、RAG 知识库建设与召回测试。

PHASE 6–7

开发与封装

程序工具开发、主 Skill 建立、子模块与工具配置、接入 RAG 与工作流。

PHASE 8–9

验收与维护

模块/工作流/业务判断/RAG/日报质量测试，版本管理与反馈迭代。

06 / RAG KNOWLEDGE BASE

RAG 知识库

七大类别，为 Skill 提供分析时所需的业务知识与参考资料。Skill 规定"如何分析"，RAG 提供"查什么知识"。

CATEGORY 01

指标体系与拆解公式

核心指标定义、分子分母口径、指标关联关系与拆解公式。

CATEGORY 02

指标异常判断

成本/流量/转化/销售指标异常的分析路径与排查依据。

CATEGORY 03

Meta Ads 平台知识

账户结构、ABO/CBO、竞价与学习机制、版位受众、Breakdown。

CATEGORY 04

素材分析与优化

四象限、素材疲劳、Hook、人物场景卖点、CTA 与素材测试。

CATEGORY 05

Shopify 独立站转化

LPV / ATC / IC / Purchase 四环节诊断与网站漏斗知识。

CATEGORY 06

海外投放业务知识

投放基础、归因与 Pixel、跨境运营、市场差异、预算扩量。

CATEGORY 07

案例知识库

账户分析、素材优化、转化漏斗优化的可复用案例结构模板。

SOURCE RULE

来源分级

区分业务已确认 / 外部资料 / AI 整理 / 待确认，外部知识不得覆盖业务规则。
